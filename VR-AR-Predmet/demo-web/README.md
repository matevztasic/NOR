# Interaktivni demo (brskalniški proof-of-concept)

`index.html` je samostojna, delujoča spletna stran (brez zunanjih knjižnic, odpre se v vsakem brskalniku brez interneta), ki hkrati služi kot:

1. **predstavitev** projekta po točkah iz navodil (problem, rešitev, funkcionalnosti, tehnologije, dodana vrednost),
2. **delujoč interaktiven demo** – vzpon po elektrarni z gumbom/tipko presledek, zgodovinske info-točke med potjo, prihod na vrh z učinkom vrtoglavice.

To ni native VR build (za to glej `/prototype/VzponTES` – Unreal Engine C++ ogrodje), ampak hiter dokaz koncepta interakcij, primeren za predstavitev na projektorju/laptopu brez predhodne namestitve.

## Zagon
Samo odprite `index.html` v poljubnem brskalniku (dvoklik ali Chrome/Edge → Datoteka → Odpri).

## Upravljanje
- **Primi in vleci** (gumb) ali tipka **Presledek** – drži za vzpon.
- Na vrhu: premikanje miške za razgled, **Približaj se robu** za učinek vrtoglavice.
